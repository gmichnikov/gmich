MCP connectors

Two separate connectors. Add the one you want in Cursor, Claude, ChatGPT, or Claude Code. A client only sees the tools for the URL you paste.

Sports schedules

Pro, college, and some minor-league games. Times are Eastern. A distance search needs a US zip and a whole number of miles from 1 to 250.

Supported clients:

  • Cursor — mcp.json → add URL under remotes
  • Claude Desktop — Settings → Connectors → paste URL
  • claude.ai — Settings → Connectors → paste URL
  • ChatGPT — Developer Mode → add URL (Plus/Pro/Team)
  • Claude Code — claude mcp add --transport http <url>
